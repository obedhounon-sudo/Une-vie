# Une Vie — version « images » (HTML5)

Copie du jeu où tous les éléments graphiques sont des fichiers image :
- les pictogrammes (emojis) sont remplacés par des PNG (`assets/emoji/`), 458 images ;
- les courbes sont affichées comme des images ;
- le jeu est une seule page HTML (`index.html`) qui se joue dans le navigateur.

Pour itch.io : zipper `index.html` + `assets/` (index.html à la racine du zip).
